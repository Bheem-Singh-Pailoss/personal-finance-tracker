

# 💰 Personal Finance Tracker

A full-stack web application that helps users **manage income, expenses, and savings effortlessly**. Built with **React, Node.js, Express, and MongoDB**, it provides a seamless way to track transactions, analyze trends, and gain financial insights — all in one intuitive dashboard.

The app includes an **AI-powered financial assistant** that answers budgeting and investment questions specific to India, making financial planning smarter and more personalized.

---

## 🚀 Key Highlights

* **Comprehensive Dashboard:** Get a clear snapshot of your financial health with charts and recent activity.
* **Smart Analytics:** Visual breakdowns by category, monthly trends, and savings insights.
* **Advanced Filtering:** Search and sort transactions by date, type, and category.
* **Secure Authentication:** JWT-based login and password encryption.
* **AI Financial Assistant:** Chat or talk to a built-in assistant trained on Indian finance topics like SIPs, PPF, and tax deductions.
* **Responsive Design:** Works beautifully across mobile, tablet, and desktop.
* **Localized Experience:** Supports Indian currency (INR) and regional context.
* **Plan-Based Features:** Free, Pro, and Elite tiers for personal or business use.

---

## 🧠 AI Financial Assistant

The AI assistant provides **real-time guidance** on money management, savings, and investments. It includes:

* Voice interaction (no external APIs needed)
* Offline responses for common finance queries
* Optional integrations with Hugging Face, Cohere, or Gemini APIs for smarter insights

---

## ⚙️ Tech Stack

* **Frontend:** React, Tailwind CSS, Chart.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB with Mongoose
* **Auth & Security:** JWT, bcrypt, express-validator
* **Dev Tools:** Axios, Date-fns, Docker, GitHub Actions (CI/CD)

---

## 🔒 Security & Performance

* Secure user authentication and data validation
* Environment-based configuration
* Optimized for speed and scalability
* Supports Dockerized deployment for easy setup and production hosting

## 🌐 Deployment

The project supports deployment via **Docker** and **Render**, with automated CI/CD pipelines using GitHub Actions. It’s designed for scalability — suitable for both individual users and small businesses.
